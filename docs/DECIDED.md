# 已定内容登记表

常浩选定、定稿或验收一项规则、流程、做法的当轮，由做这一轮的 agent 在下面加一行，并在当轮交接里写明「已登记 DECIDED.md」。以后判断「这处算不算已定」先查这里，要改登记过的内容先单独问常浩（全局规则「已定内容要改，先单独确认」）。

- 一行一项，只增不删。常浩同意改掉某项后，新加一行，旧行的备注写「已被 <日期> 那行取代」。
- 提交号写承载这项决定的实现或记录提交；口头决定写第一次把它记进仓库的提交；本仓库没有界面，基线截图一律写「无截图」；在哪定的写得能查到（会话、PR 或 issue 编号）。
